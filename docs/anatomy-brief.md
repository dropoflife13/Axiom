- Idea: Axiom is a machine that tests AI-generated database migrations against hidden house rules, learns from failures, and is measured honestly.
- Parts, each with its real role: Task generator (seeded; 40 train / 40 dev / 120 test tasks); Executor (an LLM behind an OpenAI-compatible client, temperature 0); Oracle (PostgreSQL 16 in a container; fresh database per task; migration runs as role deployer; behavioural checks run as role application); Verdict (each failure is reported as "<fact id>: one-line statement", never the corrected SQL); Advisor (writes a lesson only from a failed verdict; a lesson is saved only if the retry then passes; one lesson per fact id); Memory (the lesson store); Retrieval (picks the top k=6 lessons by feature-flag overlap before attempt 1); Guardrails (daily call budget that fails closed, rate-limit backoff, response cache keyed by provider+model+prompt); Quarantine and promotion gate (generated rules are candidates only; a human promotes them).
- Experiment: 6 conditions x 120 test tasks = 720 trials. Conditions: A no memory no hints; B all facts in the prompt; C retrieved lessons; C0 oracle messages verbatim (no Advisor); D placebo tips; E_B static hints plus the deterministic auto-fixer.
- Rules for the figure: illustration, not telemetry; no pass rates or results anywhere; every number shown must be one of the design constants above.
